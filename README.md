# 🤖 DeepSeek Web Agent Bridge (Pro Edition)

> Автономный ИИ-разработчик на базе бесплатной веб-версии [DeepSeek](https://chat.deepseek.com) прямо на вашем компьютере.  
> **Без платных подписок, без покупки API-токенов и без ограничений сторонних платформ.**

---

## 🌟 Что умеет этот агент

- ⚡ **Полная автономность (Автопилот / Hands-Free):** DeepSeek сам генерирует план, создает файлы, правит существующий код, запускает команды в консоли и проверяет результат.
- 🔁 **Авто-продолжение («Продолжить генерацию»):** Скрипт пытается автоматически нажимать кнопку продолжения при обрыве ответа из-за лимита токенов.  
  *(⚠️ **Обратите внимание:** веб-интерфейс DeepSeek периодически обновляется разработчиками сайта, поэтому автоклик может срабатывать не всегда или требовать ручного нажатия кнопки «Продолжить»).*
- ♻️ **Безопасная работа с файлами:**
  - Удаление через **системную Корзину Windows** (`send2trash`) с возможностью просмотра (`LIST_TRASH`) и восстановления (`RESTORE_FILE`).
  - Автоматическое создание **резервных копий** в `.agent_backups/` перед каждой перезаписью файла.
- ✂️ **Точечная замена кода (REPLACE_TEXT):** Умный алгоритм замены с нормализацией отступов (Fuzzy Whitespace), позволяющий менять отдельные строки без переписывания всего файла.
- 🔌 **Поддержка протокола MCP (Model Context Protocol):**
  - Поиск коммерческих фото без 404 (Pixabay, Unsplash, Pexels + свободный поиск в Wikimedia Commons).
  - Сбор характеристик компьютера (процессор, оперативная память, свободное место на дисках).
  - Работа с локальными базами данных SQLite.
- 🎨 **Векторные иконки Lucide (GET_ICON):** Вставка чистых SVG-иконок без тяжелых библиотек.
- 🌐 **Анализ сайтов-конкурентов (ANALYZE_WEBSITE):** Парсинг структуры, CTA-элементов, цветовых палитр и шрифтов.
- 💤 **Keep-Alive фоновый режим:** Вкладка браузера не засыпает при сворачивании окна благодаря легкому Web Audio генератору.
- 🔔 **Звуковые оповещения и Panic Button:** Звуковой сигнал по завершении задачи и мгновенная остановка выполнения клавишей `Escape`.

## 🚀 Быстрый старт

### Шаг 1. Скачивание проекта
- Нажмите зелёную кнопку **`<> Code`** вверху этой страницы и выберите **«Download ZIP»**, затем распакуйте архив в удобную папку (например, на Рабочий стол).
- Либо склонируйте репозиторий через Git:
  ```bash
  git clone https://github.com/l1vensi/deepseek-web-agent.git
  ```

### Шаг 2. Установка Python
Убедитесь, что у вас установлен [Python 3.10+](https://www.python.org/downloads/).  
*При установке обязательно отметьте галочку **«Add Python to PATH»**.*

### Шаг 2. Установка зависимостей
Откройте терминал (PowerShell или Командную строку) в папке проекта и выполните:
```bash
pip install -r requirements.txt
```

### Шаг 3. Запуск локального сервера
Дважды кликните по файлу **`Запустить_Сервер.bat`** (или выполните `python agent_server.py`).  
Сервер запустится на адресе `http://127.0.0.1:5000`. Не закрывайте это окно.

### Шаг 4. Подключение к веб-версии DeepSeek
Выберите один из двух удобных вариантов:

* **Вариант А (Автоматический, через расширение):**
  1. Установите расширение **Tampermonkey** для вашего браузера (Chrome, Edge, Firefox, Яндекс.Браузер).
  2. Создайте новый скрипт в Tampermonkey и вставьте содержимое файла **`Скрипт_Для_Расширения_Tampermonkey.js`**.
  3. Сохраните (`Ctrl + S`). При открытии [chat.deepseek.com](https://chat.deepseek.com) агент подключится автоматически.

* **Вариант Б (Через консоль F12 без расширений):**
  1. Откройте [chat.deepseek.com](https://chat.deepseek.com) в браузере.
  2. Нажмите `F12` (или `Ctrl + Shift + I`), перейдите на вкладку **Console**.
  3. Скопируйте весь текст из файла **`КОД_ДЛЯ_КОНСОЛИ_F12.txt`**, вставьте в консоль и нажмите `Enter`.

В интерфейсе DeepSeek появится стильная панель управления агентом с индикатором подключения.

## 🔑 Токены и фотостоки (Опционально)

> **Агент полностью работоспособен из коробки без токенов!**  
> По умолчанию поиск иллюстраций идет по открытой базе Wikimedia Commons, а генерация картинок — через встроенный шлюз.

Если вы хотите использовать персональные аккаунты фотостоков с повышенными лимитами:
1. Создайте копию файла `my_tokens.example.txt` с именем `my_tokens.txt`.
2. Впишите свои бесплатные ключи (Pixabay, Unsplash, Pexels).
3. Файл `my_tokens.txt` автоматически защищен и **никогда не попадет в репозиторий Git**.

## 🛡️ Безопасность

- Ваши личные файлы защищены: агент запрашивает подтверждение перед потенциально деструктивными операциями.
- При перезаписи файлов автоматически создаются резервные копии в `.agent_backups/`.
- Вы можете в любой момент прервать любую операцию нажатием клавиши **`Escape`** на клавиатуре или кнопкой **«Стоп»** в браузере.
