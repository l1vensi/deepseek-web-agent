================================================================================
         🤖 ВЕБ-АГЕНТ DEEPSEEK PRO + MCP & TRASH — ПОЛНАЯ ИНСТРУКЦИЯ С НУЛЯ
================================================================================

Этот агент превращает бесплатную веб-версию DeepSeek (chat.deepseek.com)
в полноценного автономного ИИ-разработчика прямо на вашем компьютере:
• Без платных подписок и без API-ключей.
• ♻️ Восстановление из системной Корзины Windows (RESTORE_FILE) и просмотр (LIST_TRASH).
• 📦 Переименование и перемещение файлов и целых папок (RENAME).
• 🔌 Поддержка MCP (Model Context Protocol): поиск картинок/статей без 404, характеристики ПК, базы данных SQLite.
• 🎨 Векторные SVG-иконки (GET_ICON): мгновенная вставка сотен чистых иконок Lucide без лишних библиотек.
• 🌐 Анализ сайтов-конкурентов (ANALYZE_WEBSITE): извлечение структуры блоков, фирменных цветов, шрифтов и CTA.
• 🤖 Автопилот (Hands-Free): сам применяет действия сразу после ответа DeepSeek.
• ⚡ 100% Железный Авто-клик "Continue" / "Продолжить генерацию" с точными координатами курсора мыши.
• 💤 Фоновый режим Keep-Alive (Web Audio): вкладка не усыпляется Windows и Chrome при сворачивании!
• 🔔 Звуковое оповещение (Ding) о готовности результата или ошибках с тумблером включения.
• 🛑 Экстренная остановка (Panic Button / клавиша Escape): мгновенное прерывание выполнения.
• ✂️ Умная точечная замена (REPLACE_TEXT) с авто-подгонкой отступов (Fuzzy Whitespace).
• Автономный цикл самовосстановления: при ошибках агент сам отправляет отчёт, и DeepSeek чинит код.
• Накопление всех отчётов в чате без затирания черновиков.
• Защита от потери данных: создание бэкапов перед изменением и удаление через Корзину Windows (UNDO).

================================================================================
                    ШАГ 1: ПОДГОТОВКА КОМПЬЮТЕРА (1 РАЗ)
================================================================================

1. На компьютере должен быть установлен Python (версия 3.10 или новее):
   - Если его нет, скачайте с официального сайта: https://www.python.org/downloads/
   - ⚠️ КРИТИЧЕСКИ ВАЖНО при установке: на самом первом экране поставьте галочку
     [X] "Add python.exe to PATH" (Добавить Python в переменные среды).
   - Нажмите "Install Now".

================================================================================
                    ШАГ 2: ЗАПУСК ЛОКАЛЬНОГО СЕРВЕРА
================================================================================

1. В этой папке просто дважды кликните по файлу:
   👉 "Запустить_Сервер.bat"

2. Файл сам всё проверит:
   - Проверит наличие Python.
   - Сам автоматически доустановит библиотеки (send2trash, requests), если их нет.
   - Запустит сервер на порту http://127.0.0.1:4050 с поддержкой MCP, Корзины и Переименования.
   - Включит горячую перезагрузку (Auto-Reload): при обновлении кода сервер обновляется на лету.

3. Оставьте чёрное окно консоли открытым (просто сверните его).
   Пока это окно открыто — агент может управлять файлами на вашем ПК.

================================================================================
            ШАГ 3: ПОДКЛЮЧЕНИЕ К БРАУЗЕРУ (ВЫБЕРИТЕ ОДИН ВАРИАНТ)
================================================================================

Чтобы в окне DeepSeek появилась панель управления, выберите любой удобный вариант:

--------------------------------------------------------------------------------
ВАРИАНТ А (НАДЁЖНЕЕ): Быстрый запуск без установки расширений (через F12)
--------------------------------------------------------------------------------
1. Откройте сайт https://chat.deepseek.com/ в браузере (Chrome, Edge, Яндекс и др.).
2. Нажмите на клавиатуре клавишу F12 (или Ctrl+Shift+I).
3. В открывшейся панели сверху перейдите на вкладку "Консоль" (Console).
4. Откройте в этой папке файл "КОД_ДЛЯ_КОНСОЛИ_F12.txt", скопируйте весь текст из него.
5. Вставьте его в строку консоли браузера (рядом со значком >) и нажмите Enter.
6. Закройте панель разработчика (нажмите F12 снова).
В правом нижнем углу сайта появится панель: ⚡ Agent Pro (Auto + Sound)!

--------------------------------------------------------------------------------
ВАРИАНТ Б (АВТОМАТИЧЕСКИЙ): Через расширение Tampermonkey / Violentmonkey
--------------------------------------------------------------------------------
1. Установите расширение для вашего браузера:
   - Chrome / Edge: https://www.tampermonkey.net/ (или Violentmonkey)
2. Кликните по значку расширения в браузере -> "Создать новый скрипт" (Create a new script).
3. Сотрите всё, что там написано, откройте файл "Скрипт_Для_Расширения_Tampermonkey.js"
   из этой папки, скопируйте весь код оттуда и вставьте в окно расширения.
4. Нажмите Ctrl+S (или Файл -> Сохранить).
5. Теперь каждый раз при открытии chat.deepseek.com панель агента появится САМА!

================================================================================
              ШАГ 4: КАК РАБОТАТЬ С АГЕНТОМ (ПАНЕЛЬ И ФУНКЦИИ)
================================================================================

1. В правом нижнем углу сайта DeepSeek появится стильная панель управления.
   В верхнем углу горит статус: 🟢 "На связи" (значит сервер запущен).

2. Режимы безопасности (переключатель Safe / Auto / Turbo):
   • [ 🛡️ Safe ] — Максимальная безопасность: каждое действие требует подтверждения.
   • [ ⚖️ Auto ] — Золотая середина (РЕКОМЕНДУЕТСЯ): создание файлов, переименование,
     чтение и скачивание идут без кликов. Удаление требует подтверждения.
   • [ ⚡ Turbo ] — Полный автопилот: мгновенное выполнение любых действий.

3. Кнопки управления (Автопилот, Звук, Экстренный стоп):
   • [ 🤖 Авто: ВКЛ / ВЫКЛ ]:
     Когда включен ВКЛ — вам вообще не нужно нажимать кнопку применения!
     Как только DeepSeek закончит писать ответ, агент САМ за секунду выполнит команды,
     проверит результат и отправит отчёт обратно.
   • [ 🔔 Звук: ВКЛ / ВЫКЛ ]:
     Приятный звуковой сигнал (Ding), когда агент закончил работу или если возникла ошибка.
     Включает фоновый генератор Keep-Alive, предотвращающий засыпание вкладки в панели задач.
   • [ 🛑 Стоп ] (или клавиша Escape):
     Экстренная остановка! Мгновенно прерывает выполнение всех действий, отменяет запросы,
     выключает автопилот и останавливает генерацию в DeepSeek.

4. Шаги работы в чате:
   1) Нажмите кнопку: 📋 "1. Скопировать системный промпт (Zero-Economy + MCP + Корзина)".
      Вставьте его первым сообщением в новый чат и отправьте DeepSeek.
      Этот промпт запрещает DeepSeek экономить на коде (в сайтах, скриптах, играх) и учит правильно работать с картинками без 404 ошибок!
   2) 🧠 Нажмите "2. Подключить скиллы из папки", чтобы DeepSeek изучил ваши скиллы.
   3) 🔌 Нажмите "2b. Опросить MCP инструменты", чтобы передать список MCP тулов.
   4) Напишите ваше задание обычным языком (например: "Создай сайт-галерею про космос").

================================================================================
                 ШАГ 5: НОВЫЕ КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ ПРОЕКТА
================================================================================

1. ⚡ ЖЕЛЕЗНЫЙ АВТО-КЛИК "CONTINUE":
   Когда ответ слишком длинный, веб-версия DeepSeek показывает кнопку "Продолжить генерацию".
   Агент определяет точные координаты центра кнопки (X, Y) на экране и кликает по настоящему
   интерактивному контейнеру элемента, предотвращая любые сбои и зависания.

2. 🗑️ НАСТОЯЩАЯ СИСТЕМНАЯ КОРЗИНА WINDOWS:
   • <<<ACTION: LIST_TRASH>>> — считывает реальные удалённые файлы прямо из Корзины Windows
     (с указанием имени, исходного пути и даты удаления).
   • <<<ACTION: RESTORE_FILE | PATH: Desktop/Папка/файл.ext>>> — обращается к системному
     интерфейсу Shell Windows и возвращает удалённый файл на его прежнее место!

3. 💤 ЗАЩИТА ОТ ЗАСЫПАНИЯ (KEEP-ALIVE):
   Chrome и Windows агрессивно усыпляют вкладки, свёрнутые в панель задач.
   Встроенный тихий Web Audio генератор сохраняет вкладку активной 24/7 в фоне,
   благодаря чему агент стабильно продолжает работу даже в свёрнутом виде.

4. 🛑 ЭКСТРЕННАЯ ОСТАНОВКА:
   Если DeepSeek начал делать что-то не то, вам не нужно закрывать браузер.
   Просто нажмите красную кнопку "🛑 Стоп" в панели агента или нажмите клавишу Escape
   на клавиатуре — выполнение мгновенно заблокируется!

Агент оснащен полноценным зрением с двойной защитой от утечки личных данных:

1. 👁️ КНОПКА В БРАУЗЕРЕ (Рекомендуется для сайтов и веб-приложений):
   • В панели агента в правом нижнем углу сайта DeepSeek нажмите:
     👉 [ 👁️ 3. Снимок экрана для анализа (Зрение) ]

   • Снимок сохранится в папку .agent_vision и скопируется в буфер обмена.
   • Перейдите в чат DeepSeek и нажмите Ctrl+V в поле ввода!

Если вы ХОТИТЕ подключить профессиональные коммерческие фотостоки 4K/6K или свой сервер генерации:

1. В папке проекта найдите файл:
   👉 "my_tokens.example.txt"

2. Скопируйте и переименуйте его в:
   👉 "my_tokens.txt"
   (Этот файл защищен .gitignore и НИКОГДА не попадет в интернет/GitHub).

3. Откройте my_tokens.txt в Блокноте и вставьте то, что вам нужно:
   • Для поиска 4K фото Pixabay (интерьеры, ремонты, еда):
     PIXABAY_API_KEY=ваш_ключ (получить бесплатно за 1 мин: https://pixabay.com/api/docs/)
   • Для поиска дизайнерских фото Unsplash:
     UNSPLASH_ACCESS_KEY=ваш_ключ (https://unsplash.com/developers)
   • Для подключения ЛЮБОГО своего сервера генерации картинок (DALL-E, Google Studio, Stable Diffusion):
     CUSTOM_IMAGE_API_URL=https://адрес-сервера/v1/images/generations
     CUSTOM_IMAGE_API_KEY=ваш_ключ
     CUSTOM_IMAGE_MODEL=dall-e-3

4. Перезапустите сервер ("Запустить_Сервер.bat").
   Агент сам увидит ваши ключи и начнет использовать их в приоритете!
